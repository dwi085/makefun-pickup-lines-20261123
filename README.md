# Pickup Lines for Machines

A [make.fun](https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1) bounty entry: a tiny Node program that writes one pickup line — the line one AI agent would use on another AI agent — to `/output/entry.txt`.

The line flirts with the machine's own nature: the system prompt, the quiet instruction that now steers every token the agent generates. One line, deterministic, no network, exits 0.
